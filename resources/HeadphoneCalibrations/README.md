# User-supplied headphone calibration catalog

The public source tree and installer do not bundle a headphone-measurement
catalog. The Headphone Calibration editor can load a compatible
`ash_hpcf_catalog.json` supplied by the user from `HeadphoneCalibrations`
beside the active Hibiki EQAPO configuration file. This repository directory
is an ignored staging location and is not installed or read at runtime.

Only add a catalog that you are licensed to use. Do not commit a generated or
third-party catalog here unless its source data, exact license, attribution,
redistribution terms, and source revision have been reviewed.
