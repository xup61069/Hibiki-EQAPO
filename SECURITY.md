# Security policy

## Supported versions

Security fixes are provided for the latest Hibiki EQAPO GitHub release. Older releases and the original upstream branches should be treated as unsupported.

## Reporting a vulnerability

Please use this repository's **Security** tab and choose **Report a vulnerability** to open a private GitHub Security Advisory. Include affected versions, reproduction steps, impact, and a minimal proof of concept. Do not post exploit details, secrets, or sensitive device information in a public issue.

You should receive an acknowledgement within seven days. Please allow time to reproduce, prepare a fix, and coordinate a release before public disclosure.

## Release verification

Hibiki EQAPO release installers are currently unsigned. Verify the SHA-256 file attached to the same GitHub release before running an installer, and only download binaries from this repository's release page.
